AndroidX/Jetpack — shims por módulo (Apêndice D)

Fonte: RustyDroid.md Appendix D. Janela: API 26–36. Bibliotecas registradas: 46 em 6 categorias (supported 0, partial 28, stub 3, not_implemented 15).

Semântica honesta: supported é modelo host com estado para o subconjunto documentado em notes/key_apis, nunca a biblioteca inteira. partial executa um subconjunto real (DEX sobre a plataforma host e/ou shim com estado); stub é só reconhecimento; not_implemented não tem modelo. Estratégias: dex-passthrough (o DEX da biblioteca executa na VM), host-shim (host intercepta métodos listados; resto cai no DEX), host-native (só host). Presença da biblioteca num APK não é cobertura de execução — para execução use MCP get_coverage. Firebase fica no Apêndice E (gms.md).
