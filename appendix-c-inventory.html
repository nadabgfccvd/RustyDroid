Method

  • Source: SDK android.jar per level, class files parsed directly.
  • Surface membership: a prefix that is a package matches exact package only; a prefix that is a class matches the class and its nested classes.
  • rd-vm descriptor literals counts classes whose Landroid/...; descriptor appears in crates/rd-vm/src. It is a class-level signal only and does not prove that methods or behaviour are implemented.
  • API 34 uses platform-34-ext7 (ApiLevel=34, ExtensionLevel=7, IsBaseSdk=true) because no plain platform-34 package is published on dl.google.com.
